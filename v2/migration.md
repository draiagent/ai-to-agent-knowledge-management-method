2. README 繼續記錄目錄、來源權威、版本與權限。
3. 選一個高頻工作，整理目標、輸入、交付與驗收，再畫 VAD 流程。

5. 依圖卡規格寫微文字，將完整操作條件放入對應 VAC。
6. 為每次執行建立獨立任務紀錄；不將範本狀態與實例狀態混用。
7. 先用虛構會議測試，再導入已授權的真實資料。
