# AI to Agent 知識庫方法論

## 從「維護工具」到「創造價值」

**讓資料夾承載知識，讓 Agent 處理知識，讓人類運用知識創造價值。**

作者與品牌署名：**AI Coach 益力康陳董 | 2026 AI to Agent**  
版本：1.0.0｜發布日期：2026-09-19｜語言：繁體中文

這是一套以「在地資料夾＋AI Agent＋輕量閱讀介面」為核心的知識管理方法論。它將重心從命名、分類、插件與版面維護，轉向可追溯的答案、可執行的方案與可檢驗的成果。

本專案提供方法、範本及練習素材；不是已部署的搜尋引擎，也不會自動取得你的電腦檔案。使用前須在所選代理環境中授予適當的資料存取權限。

## 核心原則

1. **資產可攜**：原始檔保存在可存取、可備份的資料夾，優先採用可長期閱讀的格式。
2. **問題優先**：先說清楚要做的決策，再找資料與建立必要的結構。
3. **代理執行**：將檢索、整理、關聯及格式轉換交給 Agent，降低重複工作。
4. **按需呈現**：需要時才生成表格、圖解與報告。
5. **來源可查**：答案附檔名與定位資訊，分清事實、推論及未知。
6. **人類定奪**：重要決策由人負責，重要變更保留可回復路徑。
7. **成果衡量**：看維護時間、證據品質及任務完成度，不以筆記數量衡量價值。

## 三層架構

| 層級 | 職責 | 最小實作 |
|---|---|---|
| 資產層 | 保存原始資料、版本及來源 | 資料夾、Markdown、PDF、Word、影音 |
| 代理層 | 理解問題、檢索、核對、整合及產出 | 已授權的 AI Agent＋README 指引 |
| 表現層 | 提供適合當下任務的閱讀形式 | 預覽器、對比表、Mermaid 圖及報告 |

人類的目標設定與審核貫穿三層。這是知識庫的職責分層，不代表一個 Agent 的完整技術架構。

## 立即開始

1. 使用一份非敏感資料的副本作為試行知識庫。
2. 複製 [README 範本](templates/knowledge-base-README.md)，填入目的、範圍與來源規則。
3. 在代理環境中開啟或掛載該資料夾，先確認代理能讀到哪些檔案。
4. 選用 [提示詞](prompts/prompt-library.md)，提出一個具體問題。
5. 檢查引用與遺漏，將通過審核的成果存為新的產出檔。

也可直接使用 [虛構會議範例](examples/demo/README.md) 演練「紀錄→決策→行動」。

## 重要澄清

- 本方法論批判的是過度維護的使用方式，並非主張所有筆記軟體都採專屬資料庫或都需要複雜插件。
- 「減少整理」不等於沒有結構、版本、索引或備份；資料量與格式複雜度提高時，仍需抽取文字、OCR 或檢索索引。
- 「代理負責」不等於無限制授權，也不代表代理必然讀完所有資料或永遠正確。
- 自然語言提問只是費曼式學習的起點；還需自行解釋、找出不懂之處，再回查修正。
